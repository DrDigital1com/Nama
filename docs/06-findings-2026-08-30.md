## 2. הצ׳קאאוט איטי פי 40 משאר האתר

מדידה מהשרת אל עצמו — בלי רשת, בלי DNS, בלי הדפדפן של הלקוח:

| עמוד | זמן תגובה |
|---|---|
| דף הבית | 96ms |
| עמוד חנות | 112ms |
| עמוד מוצר | 115ms |
| **עגלה** | **2,914ms** |
| **תשלום** | **4,454ms** |

אצל לקוח אמיתי בנייד ברשת סלולרית זה יהיה גרוע משמעותית.

**הסיבה:** עמודי עגלה/תשלום דינמיים ולא נהנים ממטמון דפים. בלי Object Cache הם מריצים מחדש בכל טעינה את כל השאילתות של WPML + WPML WooCommerce + YayCurrency + AffiliateWP + שלושה תוספי SliceWP + Elementor Pro + Woodmart.

`cf-cache-status: DYNAMIC` על עמודי העגלה והתשלום — כלומר Cloudflare **לא** מגיש אותם ממטמון. זה נכון ותקין; זו לא הבעיה.

## 3. מיילים לא נשלחים

- `customer_completed_order` נכשל להזמנות #10568, #10616, #10623 — **לקוחות ששילמו לא קיבלו אישור הזמנה**
- `cancelled_order` נכשל למנהל — #10638, #10642, #10643, #10645, #10646, #10647
- `woodmart_abandoned_cart_email` נכשל — #10637, #10640, #10641, #10644

השגיאה מכילה `type.googleapis.com/google.rpc.ErrorInfo`, כלומר WP Mail SMTP מוגדר מול Google/Gmail וההרשאה נכשלת — טוקן OAuth שפג, חריגה ממכסה, או הרשאה שנשללה.

זה גם משנה את התמונה העסקית: ייתכן שחלק מ"ההזמנות הלא מושלמות" הן בעצם הזמנות שהושלמו, אבל אף אחד לא קיבל עליהן הודעה.

טבלאות גדולות נוספות: `wpml_mails` 47MB, `actionscheduler_actions` 34MB (19,580 שורות) + `actionscheduler_logs` 64,029 שורות.

שרידים: `wpgh_hustle_tracking` (18,138 שורות) מתוסף Hustle שאינו פעיל, וטבלאות בקידומת `wpq5_` מהתקנה אחרת.
